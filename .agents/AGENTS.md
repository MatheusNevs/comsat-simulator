# Regras de Permissão e Comportamento do Agente

Conforme solicitado pelo usuário, este arquivo define as restrições de permissão para a atuação da IA neste projeto:

1. **Escopo de Diretório**: O agente tem permissão para ler, criar, modificar arquivos e executar comandos **SOMENTE** dentro do diretório `/home/matheus/Documents/unb/comsat` e seus subdiretórios.
2. **Ações Não-Destrutivas**: É estritamente proibido realizar qualquer ação destrutiva. O agente NÃO deve deletar arquivos do usuário (`rm`), sobrescrever códigos importantes sem backup prévio ou rodar comandos que possam danificar o sistema.
3. **Objetivo**: O foco exclusivo é auxiliar o usuário no desenvolvimento da ferramenta computacional de dimensionamento de sistemas de comunicação via satélite.
